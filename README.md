## ⭐ Featured Project

### [BHO-PID-Optimizer](https://github.com/Abdulla-22/BHO-PID-Optimizer)
**Optimal Tuning of Dynamic Systems Using the Black Hole Optimization Algorithm** — final year project, Bahrain Polytechnic.

Tunes PI/PD/PID controllers with the Black Hole Optimization (BHO) algorithm and benchmarks the results against Ziegler-Nichols on three dynamic systems: ball-and-beam, cruise control, and DC motor.

- MATLAB App Designer GUI for simulation-based tuning
- Python desktop app with step-by-step algorithm visualization
- Direct hardware-in-the-loop tuning on an Arduino-based prototype
- Repeatability analysis over 10 independent stochastic runs
- Windows installer available in the [Releases](https://github.com/Abdulla-22/BHO-PID-Optimizer/releases)
