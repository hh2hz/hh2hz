### ⭐ Featured Project

#### [BHO-PID-Optimizer](https://github.com/Abdulla-22/BHO-PID-Optimizer)
*Optimal Tuning of Dynamic Systems Using the Black Hole Optimization Algorithm*

Tunes PI/PD/PID controllers with Black Hole Optimization and benchmarks them against Ziegler-Nichols on three systems: ball-and-beam, cruise control, and DC motor.

- MATLAB App Designer GUI and a Python desktop app with step-by-step algorithm visualization
- Hardware-in-the-loop tuning on an Arduino-based prototype
- Windows installer in the [Releases](https://github.com/Abdulla-22/BHO-PID-Optimizer/releases)
